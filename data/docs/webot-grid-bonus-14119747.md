# Webot Grid Bonus
> This article covers the Webot Grid Bonus reward program, including how to receive it, usage rules, expiration policy, and FAQs. This article is specific to the Grid Bonus reward program and does not cover the platform's general bot fee policy.
**1. What is the Webot Grid Bonus?**

The Pione.US Grid Bonus is a bonus fund provided by Webot to help users start the Grid bot.
​

**2. How can I receive this bonus?**

Generally, these bonuses are awarded when users complete certain events or tasks, and winners will receive the bonus.
​

**3. Will I be notified if I receive this bonus in my account?**

Yes, you will be notified via email and push notifications.
​

**4. Why haven't I received the second Grid Bonus?**

This may be because you already have one Grid Bonus in your account that you have not used. Once you use the first Grid Bonus, we can issue you a second Grid Bonus, third Grid Bonus, and so on. Therefore, please use your Grid Bonus to start a Grid Bot as soon as you receive it.
​

**5. What is the expiration period for the grid bonus?**

After receiving the grid bonus, you can claim the grid bonus within 5-7 days and use it for trading. If it is not claimed within 5-7 days, the grid bonus will expire.
​

**6. When will the Grid Bot stop running if I initiate it using the Grid Bonus?**

A: When using the Grid Bonus, your Grid Bot will automatically stop based on preset take-profit and stop-loss thresholds. You don’t need to worry about potential losses — any losses incurred while using the bonus will be fully covered by Webot. We recommend keeping an eye on performance to stay informed.
​

**7. Can I withdraw the Grid Bonus?**

No, you cannot withdraw the bonus funds. After receiving the bonus, you can use it to start Grid bots and you can withdraw 80% of the profits when closing the position while in profit (the remaining 20% is the management fee charged by Webot).
