# Pionex.US Will Delist some Trading Pairs
> Dear Users,To improve transaction depth and user experience, Pionex.US will delist the following trading pairs at 03:30 on June 8th, 2023 ...
Dear Users,

To improve transaction depth and user experience, Pionex.US will delist the following trading pairs **at 03:30 on June 8th, 2023 (UTC)**:

- **ATOM/BTC**

- **BCH/BTC**

- **DOT/BTC**

- **LRC/BTC**

- **MANA/BTC**

- **UNI/BTC**

- **XTZ/BTC**

**Please Note:**

- This announcement only affects registered users **after December 28th,2022 (UTC).****
**

- At the same time as the above trading pairs are delisted, the bot orders and manual orders of the corresponding trading pairs will be canceled.

- Users can trade the assets mentioned above with the USDT or USD-relevant trading pairs.
