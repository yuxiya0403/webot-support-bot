# How to Solve 2FA Code Error
> If the system keeps showing "wrong verification code" when entering the Google Authentication code, please try the following methods:
If the system keeps showing "wrong verification code" when entering the Google Authentication code, please try the following methods:

1. Synchronization time

Please update your Google Authenticator app to the latest version. The app now automatically syncs time with Google's servers. If codes aren't working, check that your device's time and date settings are set to "Automatic" or synced with the network. We'll provide general instructions for both Android and iOS to help adjust these settings.

2. Refresh the browser page or change to use the incognito mode to sign in.

3. Clear the browser cache and cookies.

4. Try to operate on the APP version again.

**FAQ**

**I have tried the steps mentioned above, but I'm still unable to resolve the issue. What should I do next?**
​**​**If the above methods cannot solve your problem, we suggest you reset your Google Authenticator. Ple_ase_ follow the instructions in [How to Reset Google Authentication](https://intercom.help/webot-support/en/articles/14119765).
