# Refill Referral Code
> If you did not enter a referral code when signing up and the conditions below are met, you can still add it later in the Webot app or on t...
If you did not enter a referral code when signing up and the conditions below are met, you can still add it later in the Webot app or on the website.

- You can only enter a referral code within 14 days of registering your Webot account.

- If you have placed trade orders after registering, you can only enter the referral code within 3 days.

👉🏻 [**App operation step**](#h_01KH2JAC98FMZV15N9N00Q9JBD)

👉🏻 [**Web operation step**](#h_01KH2JCZPYRX6YYFB6ZEW6WEV7)

App operation step

Open the [Webot app](https://www.webot.com/us/en-US/download) and click **[Account]** - **[Settings Icon]** - **[Referral code]**, input the valid referral code, and click **[Confirm]** to submit.

![](https://webot-d125655f84fc.intercom-attachments-7.com/i/o/c6h9pild/2177930950/084da51eacadeacdaf06b1133e27/15139963752207?expires=1776232800&signature=781e8854e179114fa64f81846b83e19c4a984368dc880e6f8b9d7313180ca747&req=diEgEcB9nYhaWfMW3nq%2BgQlNA62rEErreWrDfo3ehVU2qukfBKRS30FwQ6yK%0AdOz0kEi6VPSRyO5M%2BdRZhSC1alg%3D%0A)

Web operation step

Log in to your [Webot account](https://www.webot.com/us/en-US/sign), click **[Avatar Icon]** - **[Dashboard]** - **[Set]**, input the valid referral code, and click **[OK]** to submit.

![](https://webot-d125655f84fc.intercom-attachments-7.com/i/o/c6h9pild/2177930997/9613aacbfbf3a9c28974030e3cc7/15139963752335?expires=1776232800&signature=edee95f155b4d4cc4ad5d7e8dcfbe04bae8e073f3f72d96a5a070a0cce2f6f7f&req=diEgEcB9nYhWXvMW3nq%2BgVOjRaLE4YaUig5%2BrJtq6yhUGhcKHXpcXiOUowBU%0AMB7CE3MbZUUkZUCtezySwB3tiM4%3D%0A)

FAQ

**Q: I have successfully submitted a referral code. How can I remove it or change it to another one?**
**A:** Please note that once you have successfully submitted a referral code to your Webot account, it cannot be removed or changed to another one.

Please get in touch with [Webot Support](https://webot.zendesk.com/hc/en-us/requests/new) if you have any other questions.
