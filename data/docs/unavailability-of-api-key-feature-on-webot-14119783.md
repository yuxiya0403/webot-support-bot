# Unavailability of API Key Feature on Webot
> We regret to inform you that Webot currently doesn't support creating API keys.
We regret to inform you that Webot does not currently support creating API keys.

We appreciate your feedback and understand how important this is to our users. Should this feature become available in the future, we will announce it through our official channels.

Please stay tuned for any future updates regarding API keys on [Webot](http://webot.com/). We recommend you follow our official channels to stay informed about new announcements and updates.
