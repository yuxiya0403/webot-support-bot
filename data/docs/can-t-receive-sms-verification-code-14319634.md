# Can’t Receive SMS Verification Code

If you cannot receive the SMS verification code, please check whether the following conditions exist:

- **Setting the numbers as SMS blacklists.**Solution: Pionex.US's SMS channel may be shared with other providers, please confirm whether the number for sending SMS verification has been added to the blacklist by mistake. If so, unblock it.
​

- **The operation frequency is too fast, making the previous SMS verification code invalid.**Solution: Please note that the SMS verification code is valid for 8 minutes. We suggest you reduce the frequency of requests and do not repeatedly click the "Resend" button. Wait until you receive the SMS verification code or until 8 minutes have passed before requesting a new code by clicking the "**Resend**" button.
​

- **Mobile phone signal network delay.**Solution: Try enabling and then disabling flight mode to refresh the connection and then try again. Additionally, go to a place where you have better network connectivity.
​

- **The SMS was judged as spam/harassing text messages and stored in the trash.**Solution: Check the trash or spam folder manually to see if you received the SMS from Pionex.US. If the number for sending SMS verification has been added to your blacklist by mistake, please unblock it.
_ _

- **If you still cannot receive the SMS verification code, try these steps:**Click "**Change verification method**" and attempt to receive the code through a different service provider by clicking "**Resend SMS message with another telecom company**" Alternatively, you can request the verification code via phone by clicking "**Receive verification code from the phone call**".

Please get in touch with[Pionex.US Support](https://pionexus.zendesk.com/hc/en-us/requests/new) if you have any other questions.
