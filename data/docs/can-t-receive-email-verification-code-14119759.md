# Can’t Receive Email Verification Code
> If you cannot receive the email verification code, please check whether the following conditions exist:
If you cannot receive the email verification code, please check whether the following conditions exist:
​

**1. Using the wrong website/app:**
Solution: Please check the URL in your web browser to ensure you are using the correct website, [Webot](https://www.webot.com/us/en-US), instead of Pionex.US. If you are using the app, please make sure you have [downloaded the correct Webot app](https://www.webot.com/us/en-US/download).
​

**2. Check the spam folder of your email.**
Solution: If your email service provider sends Webot emails into your spam folder, you can mark them as “safe” by whitelisting Webot email addresses. You can refer to [How to Whitelist Webot Emails](https://intercom.help/webot/en/articles/14119789-how-to-whitelist-webot-email) to set it up. Addresses to whitelist: [service@webot.com](mailto:service@webot.com)
​** **

**3. Your mailbox is full.**
Solution: Delete some emails and try again. Alternatively, you may subscribe to a storage plan with your email provider to expand the storage capacity. 
​

**4. The operation frequency is too fast, making the previous email verification code invalid.**
Solution: Please note that the Email verification code is valid for 8 minutes. We suggest you reduce the frequency of requests and do not repeatedly click the "Resend" button. Wait until you receive the Email verification code or until 8 minutes have passed before requesting a new code by clicking the "**Resend**" button.
​
​**5. Using Apple’s “Hide My Email” feature.**

If you signed up for Webot via "Sign in with Apple" and selected "Hide My Email," Apple generates a random private address (e.g., [`random-string@privaterelay.appleid.com`](mailto:random-string@privaterelay.appleid.com)). Webot emails are forwarded to your primary Apple ID email, but this forwarding may sometimes be disabled.
​

Solution: Please visit the [Apple ID Management page](https://account.apple.com/account/manage/section/security) and sign in. Go to "Sign in with Apple" -> "Webot" -> "Manage settings" and ensure "Turn on forwarding" is switched ON.
​
If the problem persists after trying the steps above, please contact Webot Support for further assistance.
