# How to Export Transaction History on Pionex.US Web
> If you need to file taxes for your cryptocurrency investments, you can generate a statement of your Pionex.US account to perform tax calcu...
If you need to file taxes for your cryptocurrency investments, you can generate a statement of your Pionex.US account to perform tax calculations.

​

1. Log in to your **[Pionex.US](https://v1.pionex.us/en-US/balance/taxes)** account and click **[Wallet] - [Overview] - [Taxes]**.

![](https://webot-d125655f84fc.intercom-attachments-7.com/i/o/c6h9pild/2218022593/8225b610d739ae40464c9453484a/14351624320793?expires=1776232800&signature=0fdd5e9a01d5aa3189dcdee68d025a52f27f7691a7ba45a55a9173c6625a2d52&req=diImHsl8n4RWWvMW3nq%2BgdU2Q51m4nJeEK3IrfaCo52POpjkerW3PAUuvM74%0AGJ4s5kRGsiT1VPFMRu3ct4qGWXc%3D%0A)

2. Select **the time range** for which you want to export the report, then click **[Submit] - [OK]**.

![](https://webot-d125655f84fc.intercom-attachments-7.com/i/o/c6h9pild/2218022659/c0c7e9f9983681769610c644e771/14351662101273?expires=1776232800&signature=4774db4f937f1c207ba889b4f01a5bf2f59a31fead64eea2979863fd5173fb7b&req=diImHsl8n4daUPMW3nq%2BgTOEuWlELlEEPO2eURZ%2BTqRfS8nH7LPH8Vk8sLfb%0ASiWsBsFdudxqEF8ipK1uFUWQlxI%3D%0A)

**Please note that as generating records consumes server resources, each user can only generate up to 3 times per month.

**

3. You will receive two separate Emails or SMS reminders when the report starts to be generated and when it is completed.

![](https://webot-d125655f84fc.intercom-attachments-7.com/i/o/c6h9pild/2218022696/aa6f0d3afad2199d7853a22bcfb3/14351682669209?expires=1776232800&signature=77de1618b3bc039ea4d4cb89466c9a59777636c30d040bc3f307e20080ec5755&req=diImHsl8n4dWX%2FMW3nq%2BgY%2F4Zq8mbMSVGyNN0PGgxh9dc9qvMYMORHZkczmE%0A0PQMJjkQhdsWOFyaj1nHiCP2IfI%3D%0A)

4. Click **[Download]** to start downloading your transaction history.

![](https://webot-d125655f84fc.intercom-attachments-7.com/i/o/c6h9pild/2218022723/16b50c98d5ac407a1866bc6a5841/14351788298137?expires=1776232800&signature=ac345fedc72447bc5b3bab4f387f7800ca78a28d68dd0dbd98d6843d16000874&req=diImHsl8n4ZdWvMW3nq%2BgQqVLgDBpZdcOKUFD1Zmv0m23fAzb%2BZYHAXehibN%0ADLJie3Ib9NYkhZeGMp0xJR8WONU%3D%0A)
