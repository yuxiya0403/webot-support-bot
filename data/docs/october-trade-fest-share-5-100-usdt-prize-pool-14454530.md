**Distribution Rules:**
Winners are limited per tier. If eligible users exceed spots, priority is based on trading volume (highest to lowest). For identical volumes, the first trade time determines priority.
Example: Users A and B have 100,000 USD each, User C has 110,000 USD. With two 50 USDT rewards left, C gets one. Among A and B, the quicker first trade wins.
Each user gets the highest reward: exceeding 5,000,000 USDT earns only the 500 USDT reward.
