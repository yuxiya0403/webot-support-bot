# Webot Will Support FIL (Filecoin) Network Upgrade and Hard Fork
Dear users,

Webot will support FIL (Filecoin) network upgrade and hard fork, the specific arrangements are as follows:

- Webot will suspend the deposit and withdrawal service of FIL assets at 12:00 on November 30th, 2022 (UTC); Network upgrades and hard forks;

Notice:

- During the FIL (Filecoin) network upgrade and hard fork, FIL-related transactions will not be affected;

- This FIL (Filecoin) network upgrade, and hard fork will not generate new forked coins;

- After the FIL (Filecoin) network upgrade and a hard fork, Webot will reopen the deposit and withdrawal service of FIL assets after the network is stable, and no further announcement will be made;

For details, please refer to the following:
[Filecoin v17 Shark Network Upgrade](https://zondax.ch/blog/filecoin-v17-shark-upgrade)
