# How to Download Transaction History [App]
To download your transaction history data, follow these steps in your Webot account:

**Step 1:** Open your [Webot app](https://www.webot.com/us/en-US/download) and click [Home] - [Avatar Icon] - [Customer Support] - [Export transactions history].

![](https://webot-d125655f84fc.intercom-attachments-7.com/i/o/c6h9pild/2177930928/ee750ad1e8a95b5e65d983849dad/15220912537487?expires=1776232800&signature=c66c28fb71872731b57e176e053bb4be90cf1357951c3da296ce83811202f0d7&req=diEgEcB9nYhdUfMW3nq%2BgSubioLp%2BkwUys3wpJ7MkLd0qR%2FdePNDEY%2BZta%2Bw%0AbO4waW%2FcRSnnPBzodyrbzAXdHgk%3D%0A)

**Step 2:** Select the date range for which you want to export the report, then click [Submit] - [Confirm]- [Confirm].

![](https://webot-d125655f84fc.intercom-attachments-7.com/i/o/c6h9pild/2177931021/f252d88923fb7a09a3c183f75202/15220927318415?expires=1776232800&signature=4d26d20f1d47031df139cde9bd99d37879e10b3cd42aa06d23df2903ea537aae&req=diEgEcB9nIFdWPMW3nq%2BgY0LOBhI9Q%2F7yoHWpzU5KVe7Tdg2xnhouPETM0Lc%0Ap%2B6moIH4s6elXfE5LIRJ5L3V6tY%3D%0A)

**Step 3:** You will receive two separate Emails or SMS reminders when the report starts to be generated and when it is completed.

![](https://webot-d125655f84fc.intercom-attachments-7.com/i/o/c6h9pild/2177931080/b7a17c0bbca67623cc980d66637c/15220912538383?expires=1776232800&signature=efafa798617507100c48b683c6010f787ca7422122e57788a977424307a38979&req=diEgEcB9nIFXWfMW3nq%2BgRIf6uFvN3FnpvfSIqRWAlCQbqTcRDbX0mlZbxH%2F%0A0ebAk12nM6HrkOQXMH8HbDzBRPY%3D%0A)

**Step 4:** Click [Download] to start downloading your transaction history.

![](https://webot-d125655f84fc.intercom-attachments-7.com/i/o/c6h9pild/2177931106/264e2e3bb04dbc6fa373db8f14a9/15220927318799?expires=1776232800&signature=533c5169c317622d4be51d859d0d71f5698fd283615db1b5706e33852ac9227a&req=diEgEcB9nIBfX%2FMW3nq%2BgaQiyMLPJQSPp5Wpjtcrx3uUCacIGUjper6PinFB%0A%2BMpC8LRKRrG1Ah6nVcH0stb4OzU%3D%0A)

**Please Note:**

Please note that generating records consumes server resources, so each user is limited to generating them up to three times per month. The download link for the transaction history will be generated within 24 hours after submission. You can download the file through the App or the Web. The download link will remain valid for 7 days after it is generated, so please make sure to download it in time.
