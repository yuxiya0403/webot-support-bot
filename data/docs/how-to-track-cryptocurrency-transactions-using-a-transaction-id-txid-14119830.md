# How to Track Cryptocurrency Transactions Using a Transaction ID / TXID?
> If you are wondering when your cryptocurrency transaction will complete, you can track the transaction using a Transaction ID / TXID. Here...
If you are wondering when your cryptocurrency transaction will complete, you can track the transaction using a Transaction ID / TXID. Here are the steps to follow:

1. Locate the TXID:

The first step in tracking a cryptocurrency transaction is to locate the TXID. You can find the TXID in the transaction history or details section of your cryptocurrency wallet or exchange.

2. Use a Blockchain Explorer:

Once you have the TXID, you can use a blockchain explorer to track the transaction. A blockchain explorer is a tool that allows you to view information about transactions on a certain blockchain. There are several blockchain explorers available online, and they all work similarly. Simply enter the TXID into the search bar on the blockchain explorer website, and the website will display the details of the transaction.

3. Check The Confirmation Status:

Once you found the transaction, you will see various details about the transaction, such as the amount of the transaction, the sender and receiver addresses, and the transaction fee. You can also monitor the confirmation status of the transaction using the TXID. A cryptocurrency transaction typically requires several confirmations before it is considered fully processed. The number of confirmations required varies depending on the cryptocurrency being used.
