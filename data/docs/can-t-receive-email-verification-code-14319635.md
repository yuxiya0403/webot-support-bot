# Can’t Receive Email Verification Code
> If you cannot receive the email verification code, please check whether the following conditions exist:
> 
> Using the wrong website/app:Solut...
If you cannot receive the email verification code, please check whether the following conditions exist:

- **Using the wrong website/app:**
Solution: Please check the URL in your web browser to ensure you are using the correct website, [Pionex.US](https://www.pionex.us/en-US/), instead of Pionex.com. If you are using the app, please make sure you have [downloaded the correct Pionex.US app](https://www.pionex.us/en-US/download).
​

- **Check the spam folder of your email.**
Solution: If your email service provider sends Pionex.US emails into your spam folder, you can mark them as “safe” by whitelisting Pionex.US email addresses. You can refer to [How to Whitelist Pionex.US Emails](https://pionexus.zendesk.com/hc/en-us/articles/12521335094809) to set it up. Addresses to whitelist: service@pionex.us
** **

- **Your mailbox is full.**
Solution: Delete some emails and try again.
​

- **The operation frequency is too fast, making the previous email verification code invalid.**
Solution: Please note that the Email verification code is valid for 8 minutes. We suggest you reduce the frequency of requests and do not repeatedly click the "Resend" button. Wait until you receive the Email verification code or until 8 minutes have passed before requesting a new code by clicking the "**Resend**" button.
** **
