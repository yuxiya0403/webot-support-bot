# Refill Referral Code
> If you did not enter a referral code when signing up and the conditions below are met, you can still add it later in the Pionex.US app or ...
If you did not enter a referral code when signing up and the conditions below are met, you can still add it later in the Pionex.US app or on the website.

1. You can only enter a referral code within 14 days of registering your Pionex.US account.

2. If you have placed trade orders after registering, you can only enter the referral code within 3 days

**FAQ:**

**1. ****I have successfully submitted a referral code. How can I remove it or change it to another one?**

Please note that once you have successfully submitted a referral code to your Pionex.US account, it cannot be removed or changed to another one.

**2. After submitting the referral code, the system prompts it as invalid. How to solve this?**

Please double-check the submitted referral code. Instead of manually typing it, we recommend you copy and paste it. Additionally, please note that your Pionex.US account only supports referral codes from the Pionex.US platform. Referral codes from other platforms, such as Pionex.com, are not supported as they are different entities.

Please get in touch with[Pionex.US Support](https://pionexus.zendesk.com/hc/en-us/requests/new) if you have any other questions.
