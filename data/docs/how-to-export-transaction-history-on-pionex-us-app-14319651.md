# How to Export Transaction History on Pionex.US App
> If you need to file taxes for your cryptocurrency investments, you can generate a statement of your Pionex.US account to perform tax calcu...
If you need to file taxes for your cryptocurrency investments, you can generate a statement of your Pionex.US account to perform tax calculations.

​

1. Log in to your Pionex.US account and click **[Account] - [Setting] - [Customer support] - [Export transactions history]**.

![](https://webot-d125655f84fc.intercom-attachments-7.com/i/o/c6h9pild/2218022877/6b23914ec81c936251c86e1fa169/14352688701849?expires=1776232800&signature=a7559eda38a4d7d5ccf3f096c218c4be425025208bd019ae95640cf42a3cb2d1&req=diImHsl8n4lYXvMW3nq%2BgdmvoVYolWi3GNIlUEdd6ySq3ioEr5G0y78TeJCm%0AmJAyx9jMnY4to6wrcLe6SJ64f90%3D%0A)

2. Select **the time range** for which you want to export the report, then click **[Submit] - [Confirm]- [Confirm]**.

![](https://webot-d125655f84fc.intercom-attachments-7.com/i/o/c6h9pild/2218022920/df65cab217d2dd89c1b0c79f2416/14353488710297?expires=1776232800&signature=2e0af92e88e908509798b918a4a31121c740b482fe9563fcfafbf92249302a2f&req=diImHsl8n4hdWfMW3nq%2BgTyxsJTmOk2hkrPbjkdoYVpMJeIzOM4vfqJhHCYl%0APgzPftwQ2L2mR2O%2Bhe1fnDXCUtI%3D%0A)

**Please note that as generating records consumes server resources, each user can only generate up to 3 times per month.**

3. You will receive two separate Emails or SMS reminders when the report starts to be generated and when it is completed.

![](https://webot-d125655f84fc.intercom-attachments-7.com/i/o/c6h9pild/2218022955/003e737340eaa07788b26ec7f104/14352772580889?expires=1776232800&signature=12bfdca9f73fdffb6d127fc685e52090bacd3aab369bf3e55d036e1dfbec0ac2&req=diImHsl8n4haXPMW3nq%2BgfjcGgoKawZMhKaUsV%2FZpBXFXY680VmF%2BPiUutze%0AEgxswE0pcjxQmQXdDSxfWbCuJCg%3D%0A)

4. Click **[Download]** to start downloading your transaction history.

![](https://webot-d125655f84fc.intercom-attachments-7.com/i/o/c6h9pild/2218022995/ee4ca7bb3374572e74e41ff2428e/14353524689689?expires=1776232800&signature=925e32c44f559fc95e6d794187ac39215568d3c04275e24b0b9c0567973bb9f3&req=diImHsl8n4hWXPMW3nq%2BgaXAOMIDWoCcIWYPhpRqdyY19KYNRfiSF%2F7B2cNc%0ABUOCBjQ8MXNjeglZZypD40BV8xM%3D%0A)
