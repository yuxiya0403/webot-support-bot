# Transaction ID (TXID)

A transaction ID (TXID) or transaction hash is a unique string of characters given to every transaction verified and added to the blockchain. In other words, a TXID is an identification number that labels each transaction on the blockchain.

When you make a transaction that gets added to the blockchain, it’s given a transaction ID as a unique identifier. Depending on the blockchain used, you can find it in a blockchain explorer by searching for the transaction ID. This can be useful for verifying basic transaction information, such as the amount sent, the date of transfer, the sending/receiving address, and the number of network confirmations the transaction has received.

For example, this is the TXID of the famous Bitcoin Pizza transaction:

cca7507897abc89628f450e8b1e0c6fca4ec3f7b34cccf55f3f531c659ff4d79

You can look up these transactions by copying the TXIDs into a Bitcoin block explorer, such as [blockchain.com](https://www.blockchain.com/explorer)or many others.

When you withdraw cryptocurrency from a centralized exchange (CEX) like Webot, the platform will show you the TXID of your withdrawal transaction. On Webot, you can find this on your [Withdraw History](https://www.webot.com/en-US/balance/withdraw) page. Clicking on a TXID for a given withdrawal will take you to the relevant transaction in that blockchain’s block explorer.

If you send funds to the wrong address (or blockchain), the TXID in your withdrawal history is essential to determine whether you can recover your funds. Even so, it’s not a guarantee, and it’s best to contact support on the platform that you’re withdrawing from.
