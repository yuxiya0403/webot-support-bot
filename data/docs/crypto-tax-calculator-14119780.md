# Crypto Tax Calculator
> If you have needs to report tax, you can try to use CoinLedger to import and classify.
> CoinLedger is a third-party transaction record aggr...
If you need to report taxes on your cryptocurrency transactions, you can use the following third-party platforms to import and classify your transaction data.

**CoinTracking**

CoinTracking is a third-party transaction record aggregation platform that allows you to import your Webot transaction history CSV file and calculate your tax information for filing purposes.

**Requirements**

Before you begin, please ensure you have the following:

- A CoinTracking account: If you do not have one, you can create an account using the following link: [https://cointracking.info/](https://cointracking.info/)

- A "_for-cointracking.csv_" file. You can easily obtain this file from Webot Web or App by following the instructions in the articles below:

- [How to Download Transaction History [App]](https://webot.zendesk.com/hc/en-us/articles/14868723132815)

- [How to Download Transaction History [Web]](https://webot.zendesk.com/hc/en-us/articles/14868697610639)

After you have completed the requirements above, you can follow the steps below to import your data and calculate your taxes using CoinTracking.

**How to Import Transactions and Generate Tax Reports**

**Step 1:** Click [Imports] - [Other] - [CSV Import], then select [CoinTracking CSV Import] and click the [Choose File] button.

Note: _Please do not use Exchange → Webot. Instead, make sure to follow the above steps._
